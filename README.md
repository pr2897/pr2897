## 🧠 How I Think About Agents

An agent is a distributed system with a non-deterministic component. I build them with the same discipline:

- **Idempotent tool calls:** retries must never duplicate side effects
- **Explicit state:** memory and checkpoints are designed, not left in the prompt
- **Contained failures:** timeouts, guardrails, and fallbacks around every model and tool call
- **Full observability:** every step, tool call, and decision is traceable
- **Evals over hope:** regression suites, not just unit tests
